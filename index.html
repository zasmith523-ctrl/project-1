About This Project

This website has been built strictly using raw, semantic HTML5 without any cascading style sheets, inline styles, layout tables, or forbidden formatting tags like break elements. Every element adheres to a strict two-space indented cascade structure.

Navigation across all pages is handled cleanly through standard bulleted lists placed directly at the top of each file.
